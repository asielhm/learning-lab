ONE-TIME TEACHER SETUP

Connect your results sheet.

These files are prepared for your spreadsheet. Google requires you to authorise the script in your own account. The Google-hosted dashboard requires the teacher password; the underlying spreadsheet stays private.

Update your dashboard for every course.

The update includes 21 revision banks and 1,390 questions: Y7 Maths, Y9 Science, Y10 Chemistry and Y10 Physics. Your existing records and teacher password stay in place. New results can be filtered with dropdown tick boxes for Teacher, Class, Course and Topic, with a summary of performance by topic.

Download the complete dashboard update

  1. Open your existing spreadsheet and choose Extensions → Apps Script. Replace the contents of all three files below: Code.gs, QuestionBank.gs and Dashboard.html. Your main script may be named Código.gs; replace its contents rather than adding a duplicate script. Save.
  2. Run setupLearningLab from the editor’s function menu. It preserves your existing tabs, results and password, and repairs complete tests missing a summary.
  3. Choose Deploy → Manage deployments → Edit (pencil) → New version → Deploy. Keep Execute as: Me, access Anyone and the same deployment URL.
  4. Return to the teacher page and click Check deployed update. When the banks show Ready, reload a new-course quiz. Test yourself will ask for student name, class and teacher; Practice will not. Complete one test, wait until all answers are confirmed saved, then check its completed score in your private dashboard.

New-course quizzes check that the deployed bank matches before enabling recording. Until confirmed, scores and answer reviews are shown on the student’s page only. The original connected quizzes keep their existing recording while you install this update. Scores from earlier local-only attempts are not in the spreadsheet; new records start with tests taken after recording is confirmed. What will be recorded?

All 21 revision question banks use the same recorder once the updated deployment is confirmed. Only Test yourself is recorded. The Answers tab stores the student name, class, teacher name, course, topic, question, selected answer, correct answer and timestamps. The Sessions tab stores completed test scores. Partial tests remain visible in the individual test answer history. Existing practice rows are preserved in the spreadsheet but excluded from the dashboard.

Google’s server calculates correctness against the question bank. A student’s name is self-reported. These records support practice and feedback; they are not verified exam identities.

If the setup function is missing or “Sign in to view results” appears

If the function menu only lists doGet, doPost, loginTeacher, logoutTeacher and getTeacherResults, copy the updated Code.gs above, replace the contents of your existing Google script file (it may be named Código.gs), save and refresh the editor. Choose setupLearningLab from the menu. The new setup and reset entries verify your Google account before making changes.

Running getTeacherResults in the editor produces “Sign in to view results” because it expects a dashboard login token. Use the teacher results page to view records.

Resetting the password or updating the script

To reset the password, run resetTeacherPassword from the Apps Script editor. It generates a new password and expires existing teacher logins. Do not share the new password in chat.

After changing the script files or question bank, use Deploy → Manage deployments → Edit → New version → Deploy. Keep the same deployment URL. When we add new question banks, we’ll update QuestionBank.gs too.

Connection failures and shared classroom devices

Students see “saved” only after Google confirms the write. Unconfirmed answers are retried and retained in the current tab across reloads, where browser storage is available. Keep the tab open until all answers are saved; closing it can lose pending answers. Name details are remembered only in the current browser tab. Students should check the displayed name before each quiz.

If your school account does not offer Anyone, its administrator may restrict public web apps. Tell me which access options you see so we can adapt the setup.
