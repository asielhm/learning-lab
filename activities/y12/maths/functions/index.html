A function assigns one output to each permitted input. The domain describes allowed inputs and the range describes resulting outputs. A formula, table and graph give different views of the same relationship, and the same-looking curve can represent different quantities depending on the axes.

A root is an input where the output is zero, while an intersection solves equality between two function values. A turning point concerns local change in a function, not simply where it crosses an axis. Set the window and inspect relevant intervals, and remember that restrictions or asymptotes can make a displayed connection misleading.

Connect it to everyday life and industry

For a height model h(t), solving h(t) = 0 can predict a landing time, while a maximum predicts a peak height. A negative root might be mathematically valid but outside the physical time interval. For prices and demand, an intersection has a different interpretation although the graphical method is similar.

01 · Read a function as an input–output rule

Writing f(x) names the output corresponding to input x; it is not the product f × x. The domain restricts valid inputs. A graph is a set of pairs (x,f(x)), so an axis label and scale are part of the meaning.

Words, symbols and units · unpack the idea

A function assigns exactly one output to each allowed input. f(x) names output for input x. In f(x) = ax² + bx + c, a,b,c are fixed coefficients and a ≠ 0 for a quadratic. The graph is the set of ordered pairs (x,f(x)). Domain restricts x; range describes attainable outputs.

Worked example · follow the reasoning

  1. For f(x) = x² − 4, f(3) = 9 − 4 = 5.
  2. For g(x) = √(x − 2), real inputs require x ≥ 2.
  3. A point (3,5) belongs to f even if it is outside the current viewing window.
02 · Distinguish roots from intersections

A root solves f(x) = 0, so it is an x-axis crossing or touch where defined. An intersection of f and g solves f(x) = g(x). A numerical answer needs a chosen interval or starting region and a check that the plotted behaviour is not a discontinuity.

Words, symbols and units · unpack the idea

A root is an input where f(x) = 0, so its graph meets the x-axis. An intersection solves f(x) = g(x) and has coordinates (x,y). A numerical solver may find only one root depending on starting bounds; check the whole relevant domain and whether discontinuities or tangencies matter.

Worked example · follow the reasoning

  1. For f(x) = x² − 4, roots are x = −2 and x = 2.
  2. The intersection of y = x² and y = 2x satisfies x² = 2x, giving x = 0 or 2.
  3. The corresponding intersection points are (0,0) and (2,4), not just the x values.
03 · Interpret turning points and models

A local maximum or minimum concerns nearby function values. A plotted turning point should be checked within the relevant domain and scale. A mathematical function can be evaluated beyond its useful modelling interval, so ask what each input and output means.

Words, symbols and units · unpack the idea

A turning point is a local change between increasing and decreasing. The vertex of ax² + bx + c has x = −b/(2a), with y found by substitution; a,b,c are coefficients. A fitted model approximates data, not a proved law. Residual = observed y − predicted y; residual patterns can reveal an unsuitable model.

Worked example · follow the reasoning

  1. For h(t) = −5t² + 20t + 1, complete the square: h(t) = −5(t − 2)² + 21.
  2. The maximum model height is 21 at t = 2.
  3. For a physical height story, negative times or times after landing may be outside the intended domain.
