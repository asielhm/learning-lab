01 / TRANSLATING

What does the story say?

A letter represents a number—not the name of an object. Identical unopened pen boxes contain the same number of pens.

x = pens in one unopened pen boxy = clips in one unopened clip box

Build the story with the + and − buttons, or type a count. Count unopened boxes here—not the pens hidden inside them.

Expression for the total number of items

An unopened pen box is one x quantity. Two identical boxes are x + x = 2x. One pen box and one clip box give x + y; their unknown counts need not be equal.

Choose the number of pen boxes, clip boxes and loose pens in the story. “Check my model” checks these counts. A correct model unlocks the next story.

A common mistake: x + y = 2x?

Different letters can represent different numbers. If x = 20 and y = 12, then x + y = 32, while 2x = 40. We can only combine terms with the same variable part.

What if four pens are lent out?

Starting with x pens and lending four gives x − 4, provided there are at least four pens to lend. If x = 20, there are 16 left. The minus sign describes the action.

Expression, equation or formula?

x + 3An expression describes a quantity.
2x + 3 = 7An equation states that two expressions are equal. This equation is true when x = 2.
n = x + 3A formula links variables: n is the total when three are added to x.

x + x ≡ 2x is an identity: both expressions have the same value for every x.

WRITE IT SYMBOLICALLY

What is the collected expression?

Use x^2 or x² for a square and x^3 or x³ for a cube. Any term order is accepted.

Explain the difference

3x + 2x = 5x: five copies of the same term.

x + x² cannot be collected: the powers differ.

x² + y² cannot be collected: the variables differ.

These shapes are a sorting model. x, x² and x³ represent different powers; they are not interchangeable quantities to measure together. Shapes are not drawn to scale.

Negative tiles indicate subtraction. A positive and a negative copy cancel. They do not mean that an object has a negative length, area or volume.

03 / EXPANDING BRACKETS

Multiply the whole bag.

Brackets group the contents of one bag. A number outside the brackets tells you how many identical copies of every item you have.

Identical groups

Every bag is identical. The multiplier applies to every term inside the brackets, not just the first one.

FROM THE CLASSROOM TO THE RULE

Build and check an expansion.

Why isn’t 2(x + 3) equal to 2x + 3?

There are two copies of x and two copies of three: x + 3 + x + 3 = 2x + 6. Opening the bags makes the missing three visible.

Another example: the price of a school bag

One bag contains three pens, a key and glasses. If p, k and g are their individual prices, one bag costs 3p + k + g. Two identical sets cost 2(3p + k + g) = 6p + 2k + 2g.

Stretch: apply the same rule to new examples

Here the pictures give way to symbols. Multiply each term, including its sign.

3(x − 2)

3 × x + 3 × (−2) = 3x − 6. Subtraction is an operation, not a bag containing negative physical objects.

−(16 − b)

The factor is −1: −1 × 16 + (−1) × (−b) = b − 16.

4d(d − 4)

4d × d + 4d × (−4) = 4d² − 16d. Multiplying d by d makes d².

(e − 9)(e + 3)

Each term in the first bracket multiplies each term in the second: e² + 3e − 9e − 27 = e² − 6e − 27. This is an optional next step after single brackets.
